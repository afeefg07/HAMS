📥 Import Data (from another phone)

Paste the data you copied using Export Data on the other device into the box below (click inside the box, then press Ctrl+V or long-press → Paste), then click Import.

➡️ Go to Login Page

ℹ️ This safely combines data instead of replacing it. New assets/employees/inspections from the other device are added in; anything already on this device (matched by Asset ID / Username) is left untouched, so you won't lose your own edits.
